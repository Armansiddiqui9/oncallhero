What it does

On-Call Hero is a durable AI incident-response system built on Temporal. When a service alert fires, a workflow investigates, proposes a remediation plan, asks a human for approval, executes the fix, verifies recovery, and rolls back if verification fails — with a saga (compensation) that undoes every step in reverse order.

Key capabilities

  • Deterministic agent loop — all LLM and tool calls happen inside Temporal activities, not in workflow code.
  • Safety by design — allowlist validator blocks disallowed actions; plan must match schema; non-retryable errors escalate.
  • Exactly-once mutations — idempotency keys (`workflow_id:activity_id`) prove rollback/restart never duplicate.
  • Saga rollback — failed verification triggers compensation in reverse order; cancellation runs it too.
  • Kill-worker resume — workflow survives a worker kill because state is in Temporal; timeline renders from event history.
  • Scripted / local / hosted LLM — mode can switch between a deterministic scripted provider (for demos/replay), an Ollama local model, or Anthropic.

What the build creates

  • A working shop-api (port 9001) with health, checkout, metrics, deploys, rollback, restart, flags, and fault injection.
  • A payments-mock (port 9002) for dependency-down scenarios.
  • Scenario YAMLs (S1–S6) + runbooks + gateway routes + supervisor registry.
  • A Temporal workflow + worker + web UI with incident list, timeline, approve/reject, and chaos controls.

Common failure playbook

  • Non-determinism → search workflow for I/O, datetime, random; move to activity; replay.
  • Local model too slow → raise timeout, warm, shrink prompt, or switch smaller; scripted fallback.
  • Bad JSON → lower temp, bigger model, strengthen repair retry.
  • Queries fail → worker down; fall back to history (by design).
  • Port conflict → UI names process; kill or change config.
  • Demo breaks → backup video; narrate honestly.
